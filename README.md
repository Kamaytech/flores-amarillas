# Flores amarillas 🌼

Página animada para el 21 de septiembre: un jardín de flores amarillas en HTML, CSS y JavaScript, sin dependencias.

**Demo:** https://kamaytech.github.io/flores-amarillas/

## Personalízala desde el link

```
https://kamaytech.github.io/flores-amarillas/
https://kamaytech.github.io/flores-amarillas/?para=Jessica
https://kamaytech.github.io/flores-amarillas/?para=Jessica&msg=Eres%20mi%20flor%20favorita
```

- `para`: cambia el título a "Flores amarillas para …"
- `msg`: reemplaza el mensaje de abajo

Toca la pantalla para plantar más flores.
